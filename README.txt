MY SALARY MANAGER — REPAIRED BUILD

1. Extract the ZIP to a folder.
2. Open index.html in a modern browser (Chrome or Edge recommended).
3. Data is saved automatically in that browser's Local Storage.
4. Use Download Excel regularly to keep an external backup.
5. Excel import/export works offline (the spreadsheet library is built into index.html).
6. Import replaces the currently saved records only after confirmation and validates the expected backup sheets/version.
7. Clear Data removes all saved months from this browser after confirmation.

Notes:
- This is a local, single-browser application; data does not sync between devices or browsers.
- Do not clear browser site data unless you have an Excel backup.
- The workbook format is My Salary Manager Backup v2.
